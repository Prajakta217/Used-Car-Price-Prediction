# 🚗 Used Car Price Prediction

## 📌 Project Overview

Used Car Price Prediction is a Machine Learning regression project that predicts the estimated selling price of a used car based on its features.

The project uses historical car sales data and compares multiple regression algorithms to identify a suitable predictive model.

## 🎯 Objectives

- Analyze used car sales data.
- Perform data cleaning and exploratory data analysis.
- Engineer meaningful features.
- Train and compare regression models.
- Evaluate model performance.
- Develop an interactive web application using Streamlit.

## 📂 Dataset

- Dataset: Car Details from CarDekho
- Original records: 4,340
- Records after duplicate removal: 3,577
- Original features: 8

### Features Used

- Brand
- Fuel
- Seller Type
- Transmission
- Owner
- Car Age
- Kilometres Driven

**Target Variable:** Selling Price

## 🤖 Machine Learning Models

Four regression algorithms were evaluated:

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- Gradient Boosting Regressor

### Model Performance

| Model | MAE | RMSE | R² Score |
|---|---:|---:|---:|
| Random Forest | 159204.47 | 366340.64 | 0.5834 |
| Gradient Boosting | 157754.25 | 379171.77 | 0.5537 |
| Linear Regression | 179642.90 | 384722.65 | 0.5405 |
| Decision Tree | 199731.96 | 475334.80 | 0.2986 |

**Final Selected Model:** Random Forest Regressor

The original Random Forest model achieved the highest R² score and lowest RMSE among the four models evaluated.

## 🌐 Web Application

An interactive Streamlit application allows users to enter car details and receive an estimated selling price.

### Input Features

- Car Brand
- Fuel Type
- Seller Type
- Transmission
- Owner Type
- Car Age
- Kilometres Driven

### Run Locally

Install the dependencies:

```bash
pip install -r requirements.txt
```

Start the application:

```bash
streamlit run app.py
```
